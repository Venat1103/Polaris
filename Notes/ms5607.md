# MS 5607 `BARO 0` | `I2C 1`
  - ## Commands
    | Command (Hex) | | Bit 7 | Bit 6 | Bit 5 | Bit 4 | Bit 3 | Bit 2 | Bit 1 | Bit 0
    |-|-|-|-|-|-|-|-|-|-|
    0x48 | Convert D1 (OSR=4096) | 0 | 1 | 0 | 0 | 1 | 0 | 0 | 0
    0x58 | Convert D2 (OSR=4096) | 0 | 1 | 0 | 1 | 1 | 0 | 0 | 0
    0x00 | ADC Read | 0 | 0 | 0 | 0 | 0 | 0 | 0 | 0
    0xA0 to 0xAE | PROM Read | 1 | 0 | 1 | 0 | Ad2 | Ad1 | Ad0 | 0
  - ## Characteristics
    - ### Range: 10 to 1200 mbar
    - ### Oversampling Ratio: 4096
    - ### Conversion Time: 8.22 ms
    - ### ODR ~ 122 Hz
    - ### Resolution: 0.024 mbar
  - ## I2C
    - Address: `0b1110111`
    - Data delivered MSB first LSB last
    - Data transitioned on falling edge of SCLK
  - ## Self test at boot for later version
  - ## Power mode: 6-axis low-noise mode
  - ## Command Sequence
    The MS5607-02BA has only five basic commands:
    1. Reset
    2. Read PROM (128 bit of calibration words)
    3. D1 conversion
    4. D2 conversion
    5. Wait 10 ms (8.22 ms to be exact)
    6. Read ADC result (24 bit pressure / temperature)
    7. Run compensation
    8. Repeat from Step 3

    Visit datasheet page 9 for step-by-step calculations
